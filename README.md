# Quanta - CLI Text Editor

A lightweight command-line text editor built in C, inspired by the simplicity and efficiency of `vim`. Designed for Linux systems, this editor supports fast keyboard-based editing directly in the terminal with minimal resource usage.

## Features

- Open and edit plain text files from the terminal
- Keyboard navigation and editing
- Basic operations: insert, delete, save, and quit
- Written in C with clean, modular code
- Linux-only compatibility

## Requirements

- Linux OS
- GCC or Clang compiler
- CMake 3.0 or higher
- POSIX-compliant terminal

## Build Instructions

Clone and compile the editor:

```bash
git clone https://github.com/Kanishk-Kulshrestha/Quanta.git
cd Quanta
mkdir build
cd build
cmake ..
make
```
